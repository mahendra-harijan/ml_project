# Responsible AI Considerations

## Model Predictions are Probabilistic
The predictions generated by this system are probabilities based on historical patterns in the training data, not certainties. A high probability of selection does not guarantee success, and a low probability does not indicate a complete lack of fit.

## Historical Bias
Historical hiring data inherently contains the biases of past decision-makers. If certain groups were historically disadvantaged, models trained on that data may learn to replicate those biases unless actively mitigated.

## Protected Attributes
This model strictly avoids using protected attributes (e.g., gender, race, age, religion) as features. However, proxy variables (e.g., graduation year for age, or specific associations for demographics) can still leak bias. Continuous monitoring is required.

## Human Review is Essential
This system is a **decision-support prototype**, meant to assist recruiters by summarizing information and estimating skill matches. It must **never** be used for fully automated hiring decisions.

## Synthetic Dataset Notice
The demo uses a synthetic dataset for demonstration purposes. Accuracy metrics do not reflect real-world performance, and the model should not be deployed in production without training on validated, unbiased real-world data.
